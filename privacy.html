SITE NOTES

Small footprint.
Clear boundaries.

This portfolio is a static website. It does not require an account, connect to the lab or display live security telemetry.

Visitor data

The website code uses no analytics, tracking cookies, browser storage or contact form backend. Email links open your email application; GitHub and LinkedIn links take you to those services, whose policies apply. A hosting provider may process request logs when the website is deployed.

Public evidence

Project summaries describe a private learning lab. Credentials, complete machine exports, phone and credential identifiers and internal evidence bundles are not shipped with this site. Employment and credential descriptions come from the supplied CV; lab validation claims are limited to the documented tests.

Security and accessibility

The deployment configuration defines a restrictive Content Security Policy and other browser security headers. The site uses local assets, semantic HTML, visible keyboard focus and reduced motion support. These measures are implementation choices, not a security certification or a guarantee.

Report a problem

Email heshankodippilyge@outlook.com with a page URL and description. Please do not send secrets or sensitive third party data.
