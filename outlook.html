RESEARCH-INFORMED ROADMAP / 2026

Build for what’s next.
Prove it as you go.

My next projects focus on identity, secure delivery and AI system security. These are planned investigations with defined evidence. not claims of completed expertise.

WHY THESE DIRECTIONS

The World Economic Forum’s 2026 outlook describes a risk landscape reshaped by AI adoption, geopolitical fragmentation and uneven cyber capability. NIST’s preliminary Cyber AI Profile separates securing AI systems, AI enabled defense and countering AI enabled attacks. Those themes inform the questions below; the NIST source is a draft, not a certification standard.

01
PLANNED · IDENTITY

Cloud identity
& access assurance.

How can an environment allow legitimate work while making risky access visible?

Proposed build
A small Entra ID / Azure environment with role separation, scoped access and sign in analysis.
Evidence to publish
A threat model, role matrix, controlled access tests, investigation examples and cleanup instructions.
Success criterion
Demonstrate both an allowed workflow and a denied unauthorized workflow, with the corresponding logs.
Learning connection
Builds on ProjectX AD and LAPS work while supporting current AZ-104 study.
02
PLANNED · SECURE DELIVERY

Security checks
in the delivery path.

Can a small pipeline surface a risky change before it reaches a deployed application?

Proposed build
A sample application pipeline with secret scanning, dependency checks and review gates.
Evidence to publish
Workflow configuration, safe seeded test findings, remediation commits and a passing rerun.
Success criterion
Show a controlled failing check, explain its cause, then verify the corrected build.
Research connection
Splunk’s detection content workflow illustrates the value of testing and versioning security content. This planned project applies that engineering discipline to application delivery.
03
PLANNED · AI SECURITY

AI assistance.
Bounded authority.

What happens when an AI assisted workflow encounters untrusted instructions?

Proposed build
An isolated assistant workflow with synthetic data, constrained tools and explicit human approval points.
Evidence to publish
Trust boundaries, prompt injection test cases, tool permission outcomes and a documented failure analysis.
Success criterion
Measure safe and unsafe outcomes against a defined test set; report failures alongside successful controls.
Research connection
The NIST draft Cyber AI Profile supports separating AI system protection from AI assisted defense. SC-500 is my planned certification direction, not an earned credential.

A focused roadmap, not a list of buzzwords.

I’m prioritizing projects that extend my existing work and produce reviewable artifacts. Quantum safe migration, autonomous response and other specialized areas are not presented as current competencies.
