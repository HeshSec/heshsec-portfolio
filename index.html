THE PROBLEM → THE INVESTIGATION → THE RESULT

A blocked file is only
half the story.

The Finance file screen denied the test file, but the custom alert was missing. I traced the path from the Windows event through collection and rule matching, corrected the rule parent, and validated a fresh event in Wazuh.

View engineering notes +

The controlled file contained harmless text with a prohibited executable extension. Windows emitted SRMSVC event 8215. Linking custom rule 100201 to warning parent 60601 resolved the rule hierarchy issue. Event record 1312 was correlated with the level 10 manager and dashboard alert.

FSRM performed the preventive block. Wazuh provided central detection and alerting. This test does not establish automatic Wazuh remediation or validate the other five custom detections.
